# Contributing

Vaulta is currently a private-code project.

## Accepted

- Bug reports.
- UX feedback.
- Security concerns reported privately to the owner.
- Reproduction steps, screenshots, and device/browser information.

## Not accepted

- Pull requests.
- Code contributions.
- Fork-based feature work.
- Public redistribution of beta builds.

If you are testing Vaulta, report problems only. Do not request or modify source code.

## Maintainer note

Repository permissions must enforce this policy:

- Do not grant write access to beta testers.
- Keep the repository private if code should remain private.
- Enable branch protection on `main`.
- Require pull request review from the owner if collaborators are ever added.
